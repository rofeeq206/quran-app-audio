# Qur'an recitation audio for The Holy Qur'an app

Recitation by **Mishary Rashid Alafasy**, one MP3 per surah (`001.mp3` … `114.mp3`), 64 kbps mono.
Files are published as assets of the `alafasy-64k` release and streamed by the app.

Verse numbering follows the app's mushaf (the Bismillah is verse 1 of every surah except At-Taubah).
Verse start times live in the app (`src/data/audio-timings.json`).
